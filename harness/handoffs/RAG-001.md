# RAG-001 handoff

## Outcome

`ACCEPTED — MAIN AGENT REVIEW COMPLETE`

Implemented and accepted the permission-aware dense retrieval baseline only.
The boundary uses the existing `AuthenticatedPrincipal`, `DocumentResource`,
`PolicyEnforcementPoint`, `ChunkMetadata`, `IngestionService.retrievable_chunks`,
and provider-neutral `ModelGateway`/`ModelPolicy` path.

Candidates are tenant-scoped and checked for current `ACTIVE` document/version/index state before evidence is constructed. PDP/PEP checks use the supplied policy epoch and fail closed on stale/unavailable policy. Source fetch requires both `document:read` and `source:download`; denied fetches return `redacted=True` with no source content or citation.
