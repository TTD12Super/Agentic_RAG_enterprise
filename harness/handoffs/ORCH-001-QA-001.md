# ORCH-001 QA Handoff

## Scope

QA for the real LangGraph ORCH-001 runtime and its backend Tool Gateway.
This task intentionally changed only the four QA modules in
`tests/qa/orchestration_langgraph/` and this handoff. No production code,
contracts, task registry, frontend, infrastructure, API keys or network
providers were changed.

## Test matrix

Exactly 40 deterministic cases:

| Module | Cases | Coverage |
|---|---:|---|
| `test_behavior_component.py` | 10 | compiled graph, graph nodes, simple/complex routing, conditional recovery loop, two-round cap, four-subquery/eight-call bound, typed state, malformed evidence, deduplication, partial outcome |
| `test_contract_integration.py` | 10 | exact MVP allowlist, typed search/chunk/metadata arguments, unknown tool, missing scope, tenant binding, policy epoch, explicit tool denial, idempotent replay |
| `test_security_adversarial.py` | 10 | direct/indirect prompt injection, expired scope, workflow deadline, backend permission denial, safe exception handling, input bound, output bound, replay tampering, side-effect tool denial |
| `test_e2e_operational.py` | 10 | simple and complex user workflows, partial/insufficient/error outcomes, deadline, retry/recovery, unavailable tool, trace/principal/scope propagation, single-agent boundary, unsafe output rejection |

The cases use deterministic in-memory fakes. They exercise the real
`StateGraph.compile()` result and real `ToolGateway` validation and policy
boundary; the fakes do not bypass authorization.
