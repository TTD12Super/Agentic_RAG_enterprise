# Contributing

- Assign a task ID from `harness/tasks/tasks.json` before editing.
- Read root and scoped `AGENTS.md`; use reviewed contracts in `docs/contracts/`.
- Prefer small changes; write tests adjacent to affected modules.
- Never change a contract in secret; use `docs/contracts/CHANGE-PROCESS.md`.
- A pull request must fill `.github/PULL_REQUEST_TEMPLATE.md`, link task/ADR, report executed tests, and list security impacts.
- Default branch is protected by a human approval workflow; do not auto-push or merge.
