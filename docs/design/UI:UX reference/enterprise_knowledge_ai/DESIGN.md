## Brand & Style

This design system embodies high-precision enterprise intelligence: authoritative, calm, and frictionless. Crafted for high-stakes enterprise workflows spanning Finance, Healthcare, Technology, Consulting, and Advanced Manufacturing, it strips away decorative distraction in favor of radical clarity, spatial balance, and crisp information architecture.

The visual style is **Contemporary Minimalist Enterprise SaaS**, drawing direct inspiration from precision software environments like Linear and ChatGPT. It uses an expansive canvas of clinical white surfaces structured by razor-thin neutral borders, balanced typography, and deliberate, high-impact hits of corporate red.

Key brand tenets:
- **Precision & Restraint:** UI elements earn their place through functional utility. White space is deliberate architectural relief, not empty canvas.
- **Controlled Velocity:** Red is reserved strictly for focal points, high-intent actions, critical states, and primary interaction triggers.
- **Institutional Trust:** Neutral slates, dark charcoal text, and understated surfaces instill confidence without visual fatigue over long hours of analytic synthesis.

## Colors

The palette operates under a strict hierarchy: 75–80% clean, sterile white surfaces, 10–15% functional neutral grays for spatial boundaries and grounding typography, and 5–10% disciplined corporate red for primary actions, active navigation states, and systemic focus.

### Surface & Neutral Architecture
- **Canvas Base:** `#FFFFFF` — Pure crisp white for primary document reading, input canvases, and active viewports.
- **Subtle Surface (Level 1):** `#F9FAFB` — Workspace sidebar backdrops, toolbar fills, table header rows, and nested card fills.
- **Muted Surface (Level 2):** `#F3F4F6` — Hover states, pill badges, code blocks, and deactivated controls.
- **Borders & Dividers:** `#E5E7EB` — Single-pixel precision rules defining visual boundaries without heavy separation.
- **Border Focus / Subtle Contrast:** `#D1D5DB` — Secondary border states, active splitters, and unselected control rings.

### Typography & Content
- **Primary Text:** `#111827` — High-legibility slate charcoal for headlines, body text, and active icon labels. Avoid absolute black `#000000` to preserve typographic softness.
- **Secondary Text:** `#4B5563` — Supporting descriptions, table cells, metadata keys, and inactive tabs.
- **Tertiary / Placeholder Text:** `#6B7280` — Form input hints, timestamp labels, breadcrumbs, and hotkey legends.
- **Disabled Text:** `#9CA3AF` — Inactive actions and read-only non-interactive values.

### Corporate Red System
- **Primary Interactive:** `#C8102E` — The definitive brand accent. Reserved for primary buttons, selected navigation pills, key metric focus badges, and live AI thinking states.
- **Interactive Hover:** `#B91C1C` — State shift for primary interactive components upon cursor focus or hover.
- **Interactive Pressed / Dark Red:** `#9E001F` — Active click states, dark accent accents, and high-contrast badges.
- **Tinted Red Fill:** `#FEF2F2` — Ultra-light red wash for active selection indicators, alert banners, and tag highlights.
- **Tinted Red Border:** `#FCA5A5` — Border complement for warning states and tagged knowledge items.

## Typography

The typography uses a unified **Inter** application throughout all layers of UI, from expansive KPI displays down to tabular query trees. Inter delivers structural geometric balance, legible optical tapers, and excellent screen-rendering performance in enterprise environments.

Rules for typography execution:
- **Optical Tracking:** Tighten letter spacing slightly for headings (`-0.025em` to `-0.01em`) to create dense, confident editorial authority. Body copy maintains natural spacing for continuous readability.
- **Hierarchy through Contrast:** Rely on weight transitions (Regular `400` to Semi-bold `600`) and neutral gray steps (`#111827` to `#4B5563`) rather than drastic font size jumps.
- **Tabular Figures:** When displaying query counts, dates, computational benchmarks, and financial metrics, enforce font feature `'tnum'` (tabular figures) across all `title-*` and `body-*` tokens.
- **Capitalization:** Use sentence case across all navigation, buttons, titles, and headers. Reserve all-caps strictly for small tracking labels and status indicators (`label-sm`, tracking `0.05em`).

## Layout & Spacing

The layout is built around a hybrid **Structured Split-Pane System** typical of top-tier productivity tools: collapsible fixed-width sidebars (collapsible 260px left rails, optional 320px inspection drawers) paired with a responsive fluid canvas.

### Rhythm & Density
- Base scale adheres to a standard 4px/8px modular rhythm.
- Spacing inside data cells and interactive cards remains compact (`space-sm` to `space-md`), preserving vertical density for information-rich workflows.
- Page containers and AI query streams use generous horizontal framing (`margin: 2rem`) to anchor focus on core content streams without edge collision.

### Breakpoints & Adaptive Behavior
- **Desktop (>= 1280px):** Full multi-pane workflow. 260px persistent contextual navigation, flexible centered knowledge feed (max-width 880px for read/query zones, 100% width for tabular records), and persistent utility toolbar.
- **Tablet (768px – 1279px):** Left navigation collapses to an icon bar (64px) or slide-over drawer. Knowledge streams expand to fill the fluid canvas with 1.5rem gutters.
- **Mobile (< 768px):** Single-column stack. Side rails become standard off-canvas drawers. Page margin drops to `1rem`. Floating prompt bars dock to the bottom viewport with safe-area spacing.

## Elevation & Depth

This design system deliberately minimizes deep drop shadows, using a **Tonal Border & Micro-Shadow Architecture** akin to Linear. Surfaces feel crisp, physical, and planar rather than floating in space.

### Elevation Hierarchy
- **Level 0 (Flat Canvas):** `#FFFFFF` or `#F9FAFB` base. Zero shadow. Delineated solely via single-pixel borders (`1px solid #E5E7EB`).
- **Level 1 (Card & Content Containers):** `#FFFFFF` background with `border: 1px solid #E5E7EB` and subtle ambient diffusion:
  `box-shadow: 0 1px 2px 0 rgba(0, 0, 0, 0.05)`.
- **Level 2 (Hovered Cards & Action Drawers):** Used when interactive cards, prompt inputs, or table rows lift on hover:
  `box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.05), 0 2px 4px -2px rgba(0, 0, 0, 0.04)`.
- **Level 3 (Dropdown Menus, Modals & Popovers):** Highest enterprise level for command palettes and modal overlays:
  `box-shadow: 0 10px 15px -3px rgba(0, 0, 0, 0.08), 0 4px 6px -4px rgba(0, 0, 0, 0.03)`, coupled with `border: 1px solid #E5E7EB`.
- **Active Focus Rings:** Clean 2px ring in primary red with 20% opacity (`box-shadow: 0 0 0 3px rgba(200, 16, 46, 0.20)`), providing sharp accessibility indicators without harsh outlines.

## Shapes

The design system maintains a **Controlled Rounded** geometry (`roundedness: 2`). This aesthetic delivers contemporary software polish while preserving the structured rigor required by enterprise environments.

- **Base Radius (0.5rem / 8px):** Standard buttons, text inputs, card boundaries, modal frames, and toast notifications.
- **Small Radius (0.25rem / 4px):** Sub-elements including code badges, small tooltips, segmented toggles, and inline data indicators.
- **Large Radius (1rem / 16px):** Nested main containers, contextual insight panels, and global search bars.
- **Full Pill (`9999px`):** Status indicator tags, conversation filter pills, quick-suggestion prompt chips, and avatar containers.

## Components

### Buttons
- **Primary:** Solid corporate red (`#C8102E`) background, white (`#FFFFFF`) text, 8px border-radius, weight 500. Hover transitions to `#B91C1C`. Active click settles on `#9E001F`. Focus state applies a 3px `#C8102E` ring with 20% opacity.
- **Secondary:** Clean white (`#FFFFFF`) surface, neutral slate text (`#111827`), `1px solid #E5E7EB` border. Hover triggers `#F9FAFB` fill with `#D1D5DB` border tinting.
- **Tertiary / Ghost:** No default border or background; neutral secondary text (`#4B5563`). Hover triggers `#F3F4F6` background with `#111827` text.
- **Destructive:** White background with red text (`#C8102E`) and subtle red outline (`#FCA5A5`), shifting to filled red on secondary confirmation.

### Input Fields & Search Bars
- Standard text inputs use a pure white fill with a `1px solid #E5E7EB` border, 8px radius, and standard padding of `0.625rem 0.875rem` (10px x 14px).
- Placeholder text in `#6B7280`.
- Focus shifts border to `#C8102E` accompanied by an ambient red glow (`0 0 0 3px rgba(200, 16, 46, 0.15)`).
- AI query search inputs (ChatGPT style) feature an expanded height (`56px`), centered placement, soft shadow (`Level 2`), icon action buttons (e.g., prompt options, send arrow), and multi-line auto-grow.

### Cards & Surfaces
- Information cards feature a `#FFFFFF` body, `1px solid #E5E7EB` edge, and Level 1 micro-shadow.
- Header bars inside cards use `#F9FAFB` with a bottom border separator or sit directly on the white canvas separated by spatial padding (`space-lg`).
- Interactive dashboard widgets transition border color to `#D1D5DB` on hover.

### Chips & Badges
- **Status Badges:** Small (11px, `label-sm`), uppercase with slight letter spacing. Subtle tinted background (`#FEF2F2` for active/red, `#F3F4F6` for neutral) with 1px complementary border and dark text.
- **Interactive Query Chips:** Pill-shaped (`9999px`), white fill, `1px solid #E5E7EB` border, `#4B5563` text. Hover state shifts to `#F9FAFB` fill and `#111827` text.

### Tables & Data Lists
- Knowledge query tables feature `#F9FAFB` headers with crisp `1px solid #E5E7EB` bottom borders and uppercase `label-sm` labels.
- Rows use `#FFFFFF` backgrounds with thin horizontal dividers (`#E5E7EB`), shifting to `#F9FAFB` on hover with full-row click affordance.
- Monospaced or tabular-figured font settings applied to numbers, dates, latency indicators, and reference tokens.

### Knowledge Citations & Source Drawers
- Inline citation badges are styled as compact superscript or inline square pills (`18px x 18px` or text height) with `#F3F4F6` backgrounds, `#C8102E` active text, and soft rounded corners (4px).
- Verification drawer slides out from the right viewport (`380px` wide) using Level 3 elevation, presenting reference material on pure `#FFFFFF` alongside match confidence percentages.
