# ADR-0003 — Secure Hybrid RAG baseline in Python workers

- Status: Accepted
- Date: 2026-11-09
- Affected: RAG workers, indexing, evidence, evaluation, model gateway

## Context

The product needs measurable authorized retrieval before bounded agentic loops. The initial corpus target is about 100 documents; the 500-user capacity target is a load-test objective, not a demonstrated capability.

## Decision proposal

Build and measure this progression in Python workers:

1. Dense-only baseline.
2. Dense + BM25/lexical + RRF.
3. Add approved cross-encoder reranking.
4. Add bounded parent-child expansion with a second authorization check.
5. Add bounded single-agent LangGraph only where complexity or insufficient evidence requires it.

Every branch filters tenant, current approved ACTIVE version and ACL before results return. Evidence preserves document version, page and source span. Runtime multi-agent, GraphRAG and semantic answer caching remain outside the MVP.

## Consequences

- Evaluation can attribute quality, latency, cost and leakage changes to each step.
- RAG workers need an authenticated policy interface and versioned evidence/result schemas.
- Similarity scores are ranking signals, not confidence probabilities.
- No performance or 500-user claim is valid before a defined workload and benchmark.

## Approval

Project Owner approved this ADR as the MVP retrieval baseline on 2026-11-10. Provider choices, evaluation thresholds and worker contracts remain subject to the applicable pending decisions and later acceptance evidence.

## Owner-provided MVP parameters

- Qdrant supplies dense and sparse/BM25 retrieval with RRF fusion; OpenSearch/Elasticsearch are deferred.
- Embedding baseline: `BAAI/bge-m3`; reranker baseline: `BAAI/bge-reranker-v2-m3`.
- Structure-aware chunks target 500–800 tokens, 10–15% overlap and parent sections up to 2,000 tokens.
- The bounded agent path allows two retrieval rounds, four subqueries and eight tool calls.
- Golden Dataset proposal: at least 200 cases, with 70% Vietnamese, 30% English, at least 50 permission-negative cases and at least 30 unanswerable cases.
