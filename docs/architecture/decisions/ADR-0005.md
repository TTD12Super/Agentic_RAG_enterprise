# ADR-0005 — Contract-first cross-runtime agent development

- Status: Accepted
- Date: 2026-11-09
- Affected: all code owners, Rust Core, Python workers, frontend and tests

## Context

The project uses independent development agents, but the product runtime is a bounded single-agent RAG workflow. The MVP Core and Python workers must evolve without sharing implementation modules or silently changing security boundaries; a later Rust trial must preserve the same contracts.

## Decision proposal

- Approve versioned contracts before parallel implementation.
- Assign each task a unique ID, dependency set, owner, allowed files, acceptance tests and handoff location.
- Keep shared contracts, ADRs, task state and migrations under coordinated ownership.
- Use separate worktrees or serialized ownership for concurrent writers.
- Require real integration evidence before a task becomes DONE.
- Treat development subagents and runtime LangGraph orchestration as separate concerns.
- Keep Project Owner approval required for architecture, contracts, commit, push, merge and deployment.

## Consequences

- Local mocks can unblock isolated work but cannot prove integration or authorization.
- Rust/Python schema compatibility, worker authentication and replay behavior become explicit gates.
- A task may be code-complete while its integration gate remains BLOCKED.
- The Main Agent coordinates but does not self-approve shared architecture.

## Approval

Project Owner approved this ADR as the MVP delivery-governance baseline on 2026-11-10. Contract, security, deployment, Git and release approvals remain separate gates.

## Owner-provided contract baseline

- Public APIs use REST/HTTP JSON and OpenAPI 3.1 under `/api/v1`.
- Worker payloads use JSON Schema with `schema_version`, UTC timestamps, idempotency keys, `X-Request-ID` and W3C `traceparent`.
- Job states are `QUEUED`, `RUNNING`, `PAUSED`, `RETRY_SCHEDULED`, `COMPLETED`, `FAILED` and `CANCELLED`; maintenance is a system mode.
- Prompt source-of-truth is versioned Git content; prompt, model, retrieval-config and policy versions are recorded with answers.
